# WayYaam Касса

Адаптивная offline-first PWA-касса продуктового магазина: планшет в горизонтальной ориентации, телефон в вертикальной, несколько газелей/базарных точек, продажи по весу, штукам или на заданную сумму, ежедневные расходы, контроль порчи и локальная база Dexie/IndexedDB.

Визуальный макет и подробные критерии приемки находятся в [ТЗ](docs/TZ-WAYYAAM-POS.md).

## Стек

- React + TypeScript + Vite
- Dexie + IndexedDB
- vite-plugin-pwa + Service Worker
- Полностью локальное хранение данных

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка production:

```bash
npm run build
```

## Что уже есть

- Экран быстрой продажи с лентой товаров
- Четыре товара в строке на планшете и компактная касса для `1040×576`

- Весовые и штучные товары; режимы `По весу` / `По количеству` и `На сумму`
- Раздельный учет запроса клиента, фактической суммы и разницы
- Настраиваемые быстрые значения веса и суммы
- Крупная цифровая панель
- Быстрое изменение веса, суммы и цены
- Скидка, точный фактический результат и расчет сдачи
- Общая партия остатка для нескольких вариантов товара
- Товары, партии, поступления, порча по весу или мешкам, расходы
- История и отчеты по расчетной/фактической выручке и потерям
- Ежедневные расходы по аренде, обеду, транспорту и другим категориям
- Системная отправка или скачивание краткого аналитического отчета
- Версионированный экспорт и транзакционный импорт JSON с проверкой данных
- Демо-данные
- Installable PWA

## Как открыть на телефоне через GitHub и добавить на экран домой

### 1. Загрузить проект на GitHub

```bash
git add .
git commit -m "bazaar pwa mvp"
git push origin main
```

### 2. Включить GitHub Pages

В репозитории:

1. `Settings`
2. `Pages`
3. `Source = GitHub Actions`

В проект уже добавлен workflow `.github/workflows/deploy.yml`, который соберет `dist` и опубликует сайт.

### 3. Открыть ссылку на телефоне

После деплоя GitHub Pages даст ссылку вида:

`https://USERNAME.github.io/REPO/`

Откройте ее на телефоне.

### 4. Добавить на главный экран

#### Android / Chrome

1. Открыть сайт
2. Нажать меню браузера
3. Выбрать `Установить приложение` или `Добавить на главный экран`

#### iPhone / Safari

1. Открыть сайт
2. Нажать `Поделиться`
3. Выбрать `На экран "Домой"`

После первого открытия приложение кэшируется сервис-воркером и дальше может работать офлайн.

## Важно

- GitHub Pages все равно нужен для первой загрузки по ссылке
- После установки приложение работает как локальная PWA
- Данные хранятся только на конкретном устройстве в IndexedDB
- Для переноса данных между телефонами используйте экспорт/импорт JSON
